The first public release. It is a single commit of a project developed in a private
repository; [docs/project-summary.md](https://github.com/bayesianHimanshu/meridian-fleet/blob/v1.1.0/docs/project-summary.md)

## How it was recorded

- **A copy of the ledger.** The recording read only a copy, opened with SQLite's backup
  API. The copy verified at 20,212 events, with its last hash equal to the real ledger's.
- **A read-only API.** The API ran in a read-only mode in which every request other than
  GET, HEAD or OPTIONS is refused with 403. During the recording, one real decision request
  was sent as the operator `operator:demo-recorder`, never as a person, and was refused
  with 403. No form was submitted.
- **Reproducible.** The same ledger copy and script give the same video, byte for byte:
  still frames, a deterministic local voice, and fixed clocks in the browser and the API.

## The question box

- **How it answers.** By retrieval (BM25 over the transcript and the project's documents),
  never generation. It needs no API key and no model.
- **When it declines.** When the best passage covers less than half of the question's
  weight. Since run 2, words that appear in no passage count against a match.

Results as reported in PR 37 (a decline counts as no hit):

| Set | Run | Questions | Top-1 | Top-3 | False declines | Correct declines |
|---|---|---:|---:|---:|---:|---:|
| Original, one source | 1 | 20 | 11 | 14 | 3 | |
| Original, one source | 2 | 20 | 10 | 13 | 4 | |
| Original, two sources | 1 | 5 | 3 | 1 | 1 | |
| Original, two sources | 2 | 5 | 2 | 1 | 2 | |
| Original, not covered | 1 | 5 | | | | 1 |
| Original, not covered | 2 | 5 | | | | 4 |
| Held-out, answerable | 2 | 10 | 7 | 9 | 1 | |
| Held-out, not covered | 2 | 10 | | | | 10 |

How hits are counted:
- **Two-source question:** top-1 = the first passage is from either expected source;
  top-3 = both expected sources are in the top 3.
- **Run 2's false declines:** a03, t02 and b02. Each was declined because ordinary words
  in the question appear in no passage.
- **Still answered:** u04 ("Which patients received the placebo?") matches the narration
  without being answered by it.

These results come from the index as it was in PR 37 (148 passages). The page in this
release indexes the documents as they are now (150 passages), and that version was not
evaluated again.
